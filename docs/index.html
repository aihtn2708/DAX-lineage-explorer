Lineage for every DAX measure in a model, from one query.

Run EVALUATE INFO.MEASURES() against a Power BI, Fabric or Analysis Services model, export the result to Excel, and drop it here. You get a graph of what each measure reads, what reads it, and the DAX behind it.

Drop your export here

.xlsx, .csv, .tsv or .json. Several files at once, or one workbook with a sheet per query.

Files are read in this browser tab. Nothing is uploaded anywhere.

Or paste the result grid (copy table from DAX query view)
Tab- or comma-separated, header row first.

1 · Run the queries

  1. Power BI Desktop: DAX query view
  2. Fabric: the semantic model's DAX query editor
  3. DAX Studio, SSMS or Tabular Editor on an XMLA endpoint

Only INFO.MEASURES() is required. Add INFO.COLUMNS() so a bare [Amount] can be told apart from a missing measure.

2 · Export to Excel

  • Paste each result into its own sheet, named INFO.MEASURES, INFO.TABLES, INFO.COLUMNS
  • Or save each as CSV and drop them together
  • Sheet names are optional; the columns give each one away
